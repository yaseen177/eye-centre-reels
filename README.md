# eye-centre-reels

Public hosting for The Eye Centre's daily social videos (Instagram + Facebook Reels).

Instagram and Facebook can only publish a video from a public link, so each day's video is
committed to `videos/` and served by GitHub Pages at
`https://yaseen177.github.io/eye-centre-reels/videos/<file>.mp4`.

- `videos/` — published videos (safe to delete old ones once posted)
- `studio/` — the scripts that build the videos (added next)
